# 🚀 Prompt to Infrastructure - 1 Hour Demo Plan

## 🎯 Goal
Build a minimal working demo that shows:
1. User enters a prompt (dummy text)
2. "Generates" a hardcoded Terraform script
3. Displays code + visual diagram side-by-side
4. Diagram uses React Flow with 5 AWS components

**Time Budget: 60 minutes**

---

## 📋 What We're Building

### **Components in the Demo:**
1. **Lambda Function** (Compute)
2. **DynamoDB** (NoSQL Database)
3. **ElastiCache** (Cache)
4. **SQS** (Queue)
5. **API Gateway** (Bonus - Entry point)

### **Architecture Story:**
"Serverless API that processes requests asynchronously"
- API Gateway receives requests
- Lambda processes them
- DynamoDB stores data
- ElastiCache caches frequent queries
- SQS queues background jobs

---

```tsx
import { memo } from 'react';

const colorMap: Record<string, string> = {
  cyan: 'from-cyan-500 to-blue-500',
  blue: 'from-blue-500 to-indigo-500',
  purple: 'from-purple-500 to-pink-500',
  green: 'from-green-500 to-emerald-500',
  orange: 'from-orange-500 to-red-500'
```

#### **2. Prompt Input Component** (`src/components/PromptInput.tsx`):

```tsx
import { useState } from 'react';

interface PromptInputProps {
  onGenerate: () => void;
}

export const PromptInput = ({ onGenerate }: PromptInputProps) => {
  const [prompt, setPrompt] = useState('');

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (prompt.trim()) {
      onGenerate();
    }
  };

  return (
    <div className="w-full mb-6">
      <form onSubmit={handleSubmit} className="flex gap-4">
        <input
          type="text"
          value={prompt}
          onChange={(e) => setPrompt(e.target.value)}
          placeholder="Describe your infrastructure... (e.g., 'serverless API with database and cache')"
          className="
            flex-1 px-6 py-4 
            bg-navy-800/50 
            border border-white/10 
            rounded-lg 
            text-white placeholder-white/40
            focus:outline-none focus:border-cyan-500/50
            backdrop-blur-sm
          "
        />
        <button
          type="submit"
          disabled={!prompt.trim()}
          className="
            px-8 py-4 
            bg-gradient-to-r from-cyan-500 to-blue-500
            hover:from-cyan-600 hover:to-blue-600
            disabled:from-gray-600 disabled:to-gray-700
            disabled:cursor-not-allowed
            text-white font-semibold rounded-lg
            transition-all duration-200
            shadow-lg shadow-cyan-500/50
          "
        >
          Generate
        </button>
      </form>

      {/* Example prompts */}
      <div className="mt-3 flex gap-2">
        <span className="text-white/60 text-sm">Try:</span>
        <button
          onClick={() => setPrompt('Serverless API with database and cache')}
          className="text-cyan-400 text-sm hover:text-cyan-300 underline"
        >
          Serverless API
        </button>
        <button
          onClick={() => setPrompt('Event-driven architecture with queues')}
          className="text-cyan-400 text-sm hover:text-cyan-300 underline"
        >
          Event-driven
        </button>
      </div>
    </div>
  );
};
```

### **Minutes 35-50: Main App Assembly**

#### **App Component** (`src/App.tsx`):

```tsx
import { useState } from 'react';
import { PromptInput } from './components/PromptInput';
import { CodeDisplay } from './components/CodeDisplay';
import { DiagramCanvas } from './components/DiagramCanvas';
import { TERRAFORM_CODE } from './data/hardcodedTerraform';

function App() {
  const [showResults, setShowResults] = useState(false);
  const [isGenerating, setIsGenerating] = useState(false);

  const handleGenerate = () => {
    setIsGenerating(true);
    
    // Simulate "generation" delay for realism
    setTimeout(() => {
      setShowResults(true);
      setIsGenerating(false);
    }, 1500); // 1.5 second delay
  };

  return (
    <div className="h-screen flex flex-col bg-navy-900">
      {/* Header */}
      <header className="border-b border-white/10 bg-navy-800/50 backdrop-blur-sm">
        <div className="px-8 py-4">
          <h1 className="text-2xl font-bold text-white flex items-center gap-3">
            <span className="text-4xl">⚡</span>
            Prompt to Infrastructure
          </h1>
          <p className="text-white/60 text-sm mt-1">
            AI-powered cloud infrastructure generation
          </p>
        </div>
      </header>

      {/* Prompt Input */}
      <div className="px-8 py-6 border-b border-white/10 bg-navy-800/30">
        <PromptInput onGenerate={handleGenerate} />
      </div>

      {/* Loading State */}
      {isGenerating && (
        <div className="flex-1 flex items-center justify-center">
          <div className="text-center">
            <div className="inline-block animate-spin text-6xl mb-4">⚡</div>
            <p className="text-white/80 text-lg">Generating infrastructure...</p>
          </div>
        </div>
      )}

      {/* Split View: Code + Diagram */}
      {!isGenerating && (
        <div className="flex-1 flex overflow-hidden">
          {/* Left: Code */}
          <div className="w-1/2 border-r border-white/10 p-6">
            <div className="mb-4">
              <h2 className="text-white font-semibold flex items-center gap-2">
                <span>📝</span>
                Terraform Code
              </h2>
            </div>
            <CodeDisplay code={TERRAFORM_CODE} show={showResults} />
          </div>

          {/* Right: Diagram */}
          <div className="w-1/2 p-6">
            <div className="mb-4">
              <h2 className="text-white font-semibold flex items-center gap-2">
                <span>🏗️</span>
                Architecture Diagram
              </h2>
            </div>
            <div className="h-[calc(100%-3rem)]">
              <DiagramCanvas show={showResults} />
            </div>
          </div>
        </div>
      )}

      {/* Footer Stats (when results shown) */}
      {showResults && (
        <div className="border-t border-white/10 bg-navy-800/50 px-8 py-4">
          <div className="flex gap-8 text-sm">
            <div>
              <span className="text-white/60">Resources:</span>
              <span className="text-cyan-400 ml-2 font-semibold">5 resources</span>
            </div>
            <div>
              <span className="text-white/60">Est. Cost:</span>
              <span className="text-green-400 ml-2 font-semibold">$45/month</span>
            </div>
            <div>
              <span className="text-white/60">Security Score:</span>
              <span className="text-blue-400 ml-2 font-semibold">8/10</span>
            </div>
          </div>
        </div>
      )}
    </div>
  );
}

export default App;
```

## 🔧 Troubleshooting

### **Common Issues:**

**React Flow not showing:**
- Check `reactflow/dist/style.css` is imported
- Ensure parent div has explicit height

**Nodes overlapping:**
- Adjust positions in `diagramNodes.ts`
- Increase spacing between nodes

**Tailwind not working:**
- Verify `tailwind.config.js` content paths
- Check `@tailwind` directives in `index.css`

**TypeScript errors:**
- Run `npm install --save-dev @types/node`
- Add type definitions as needed
